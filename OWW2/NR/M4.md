but radio waves can override that somehow

remove radio waves -> change alignment to the magnetic field
during alignment they send radio waves back
in the start, all water molecules still aligned -> add up to big boi radio wave
over time desynchronisation -> signal gets weaker

magnetic fields disturbances cause *faster* desynchronisation

deoxynated blood causes disturbances
oxynated blood doesnt

active -> more oxygen -> less disturbances -> less desync -> stronger signal
inactive -> less oxygen -> more disturbances -> more dsync -> weaker signal
