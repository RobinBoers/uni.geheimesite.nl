Perceptie = het deel van de sensorische input dat verwerkt wordt en waar je je bewust van bent.

Aandacht = selectie van sensorische input die wordt verwerkt of genegeerd.

Top-down aandacht = beslissingsaandacht. Je kiest bewust om ergens aandacht aan te geven. Gebeurt in de prefrontal cortex.

Bottom-up aandacht = niet-vrijwillige aandacht. Iets 'pakt' je aandacht (bijvoorbeeld een telefoon of het horen van je naam). Gebeurt in de sensory cortexes.

Bewustzijn = iets dat je weet / kan herinneren? Ik kon geen exacte definitie vinden in de video of Ward.

Exogene aandacht = hetzelfde als bottom-up aandacht, namelijk geleidt door externe stimulus.

Endogene aandacht = hetzelfde als top-down aandacht, namelijk bewust geleidt.

Automatische aandacht = weer hetzelfde als bottom-up aandacht (??).

Bewust gestuurde aandacht = weer hetzelfde als top-down aandacht (??).

Onbewuste processen (subliminal en preconscious) = sensorische input die te zwak/kort is om waar te nemen, of niet verwerkt wordt omdat er geen aandacht aan besteedt wordt.

Global (neuronal) workspace = informatie wordt bewust waargenomen als verschillende hersendelen deze verwerken. Ik kon dit begrip ook niet vinden in Ward of de video, dus ik heb het gegoogled.

Careful spending of mental currency = er is een maximale capiciteit aan sensorische input die het brein tegelijk kan verwerken. Dit kan worden vergeleken met/gezien als "mentale currency". Door middel van aandacht hoeft alleen relevante sensorische input verwerkt (aka "uitgegeven") te worden. Dit is beter voor de overlevingskans. Dus eigenlijk is dit een synoniem van/reden voor/gevolg van aandacht.

Prioriteren = wederom een ander woord voor aandacht (??).

Andere begrippen uit de video:

Serial processors = maximaal één ding tegelijk kunnen doen.

Multi-tasking = heel snel heen-en-weer switchen tussen twee taken, waardoor de illusie er is dat je meerdere dingen "tegelijk" doet. (Maar het is dus sequentieel, niet parallel.)

Inattentional blindness = iets onverwachts niet merken omdat we te gefocussed zijn op iets anders. Side-effect van focus/aandacht.

Stroop-effect = door tegenstrijdige sensorische input verstoring, waardoor reactietijden en accuratie afneemt.
