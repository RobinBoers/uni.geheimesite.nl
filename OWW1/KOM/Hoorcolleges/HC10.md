nulhypothese waar maar verworpen -> type I (false positive)
(we denken dat een medicijn werkt terwijl het niks doet -> onnodig meer research en mogelijk bijwerkingen)
nulhypothese fout maar aangenomen -> type II (miss)
(we denken dat een medicijn niet werkt terwijl het eig wel werkt -> we zouden mensen betere behandeling kunnen geven)

de nulhypothese is goed en we houden hem aan => hoge betrouwbaarheid (kans dat dit gebeurt)

| echt -> | geen verschil | wel verschil |
| h0 aangehouden | betrouwbaarheid | miss (beta) |
| h0 verworpen | false positive (alfa) | power |

type I errors voorkom je door een lagere alfa (alfa bepaalt of we de nulhypothese verwerpen; lagere alfa => meer verworpen H0 => minder false positives)
p is de kans dat we dit of extremer vinden onder h0, dus alfa is de maximale kans die we toestaan dat we fout zitten.

type II errors worden veroorzaakt door een range aan factoren
(je kan de kans voor deze dus niet bepalen, maar wel schatten)

- beta is de kans dat je de nulhypothese aanneemt wanneer hij verworpen moet worden
- power is de kans dat je de nulhypothese verwerpt als hij verworpen moet worden

(power = 1 - beta)

lage alfa zorgt ervoor dat je sneller een nulhypothese minder snel verwerpt => dus meer type II errors
(lage alfa => lage power)
