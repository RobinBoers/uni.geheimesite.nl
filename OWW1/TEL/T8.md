Extended Reality (XR):

- Augmented Reality (AR): project on top of world via screen
- Mixed Reality (MR): project on top of world via headset
- Virtual Reality (VR): entirely virtual world
  - low-immersion: only on a screen
  - high-immersion: 360deg environment
  ^this last thing is what we use the term 'VR' for rn.

Key concepts:

- Presence = being there
- Immersion = ability to shut outside world out
    - haptics
    - object interaction
    - user-to-user interaction
    - movement
- Embodiment = substitute real body with virtual one
  (from 1st person pov)

Challenges:

- bandwidth (internet speed basically)
- disabilities
