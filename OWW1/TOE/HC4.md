informatie over populatie

te groot om iedereen te bevragen => steekproef

survey lifecycle

twee armen:
- meetproces: de vragen
- vertegenwoordiging: de respondenten

je kan daarin fouten maken:
1. dekkingsfout
2. steekproeffout
3. nonresponsefout
4. aanpassingsfout
5. responsefout
6. verwerkingsfout

sommigen onvermijdelijk, sommige kan je iets aan doen

eerste 4: vertegenwoordiging
laatste 2: vragenlijst

dekkingsfout:

aselecte steekproef: je hebt een lijst van *alles* nodig

lijst = steekproefkader, soms niet *exact* overeenkomend met populatie
(aka is benadering van populatie)

vertekening door dekkingsfout -> slect als verschil systematisch is
(aka niet random mensen missen of extra, maar specifieke kenmerken)

dus kan willekeurige fout (random error) of systematische fout (=> bias) zijn

random error -> betrouwbaarheid in geding
systematische fout -> validiteit in geding

steekproeffout:

steekproef kan verschillen van populatie (niet representatief zijn)
je weet niet hoe groot de steekproeffout is
we kunnen wel iets zeggen over gemiddelde van steekproeffouten
= standaardfout (BAM DAT WIST IK)

grotere steekproef -> kleinere standaardfout

je kan perongeluk mensen binnen het steekproefkader hebben maar buiten de populatie
-> oplossing: inclusie/exclusie criteria in de vragenlijst om die respondenten eruit te filteren
-> andersom kan je niet oplossen (dat mensen binnen de populatie vallen maar niet in het steekproefkader)

nonresponsefout:

geen antwoord krijgen van mensen die geselecteerd waren voor de steekproef

twee vormen:
- unit-nonresponse: mensen weigeren alles
- item-nonresponse: mensen weigeren bepaalde vragen

redenen:
- technische problemen
- gebrek aan motivatie of interesse
- gebrek aan vertrouwen bij gevoelige vragen

=> non-response bias -> weer vooral een probleem als het gaat om systematische verschillen

aanpassingsfouten:

- wegingen van groepen aanpassen:
  - ondervertegenwoordigde groepen meer laten wegen
  - oververtegenwoordigde groepen minder laten wegen
- ontbrekende antwoorden aanvullen door imputatie:
  missende gegevens laten schatten door een statistisch model, op basis van alle antwoorden die *wel* gegeven zijn

maar je kan hierin ook fouten maken

antwoordproces:
- begrijpen: woorden, formulering, interpretatie
- ophalen: geheugen goed?
- judgement: accuraatheid van antwoordt, formulering
- response: kan ik dit antwoorden (met de opties), en ben ik bereidt dit te doen

responsefouten (of meetfouten):

fouten gemaakt door respondent

onjuiste antwoorden door:
- mode effect: format
- question bias: vraagstelling
- response bias: gedrag (bereidheid)

verwerkingsfout:

fouten gemaakt door analyst

- foutieve gegevensinvoer
- (her)codeerfouten
- omgaan met vertrouwelijke informatie
- foute berekeningen
